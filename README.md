# 青禾陪诊 H5 原型

根据用户提供的陪诊小程序参考截图制作的手机 H5 演示。页面采用独立的清新绿蓝视觉、虚构品牌和虚构数据。

## 直接运行

使用浏览器打开 `index.html` 即可。也可以在本目录启动静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173`。

## 已实现

- 首页横幅、服务搜索、快捷入口、服务套餐和服务列表
- 服务详情、服务流程和预约须知
- 陪诊师／家庭护士切换、人员搜索与详情
- 医院、日期、时段、就诊人和联系电话预约表单
- 订单创建、状态筛选、详情、取消和模拟支付
- 个人中心、订单状态快捷入口和功能反馈
- 使用 `localStorage` 保存演示订单
- 手机优先布局，桌面端以 520px 宽手机画布展示

## 演示说明

- 当前没有后端、数据库、真实登录、短信、支付和退款。
- “模拟支付”只会在浏览器本地把订单改为“待指派”，不会扣款。
- 服务人员、证件、评价、医院、价格和成交量均为界面演示数据。
- 医疗场景图片通过项目要求的文生图接口加载，Lucide 图标通过 CDN 加载，离线环境可能无法显示这些资源。

## 主要文件

- `index.html`：页面入口
- `styles.css`：清新绿蓝视觉和响应式布局
- `app.js`：页面数据、路由、预约及订单交互
- `DEVELOPMENT_PLAN.md`：后续后端、后台、支付和上线计划
